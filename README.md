F28377D Firmware Project
=========================

Overview
--------

This repository contains firmware and supporting files for a project targeting the Texas Instruments TMS320F28377D (C2000) microcontroller. The codebase includes device drivers, application logic, EtherCAT support, and build scripts for CPU1 (FLASH and RAM targets).

Repository Structure
--------------------
- `Core/` - Project core modules and application source under `Core/src` and headers under `Core/inc`.
- `device/` - MCU startup, device-level code and low-level glue (device.c/h, driverlib wrappers).
- `driverlib/` - TI driver library sources and headers used by the project.
- `ECAT/` - EtherCAT-related sources and drivers.
- `LibCtrl/` - Control libraries and headers used by the application.
- `CPU1_FLASH/`, `CPU1_RAM/` - Build outputs, linker scripts, and makefile fragments for different targets.
- `syscfg/` - Board and peripheral configuration files generated by the project tools.
- `docs/` - Project documentation (Chinese language notes and command references).
- `makefile`, `sources.mk`, `objects.mk` - Build system makefiles used to build the project from command line.

Key Files
---------
- `main.c` - Application entry point.
- `makefile` - Top-level makefile to build CPU1 targets.
- `2837xD_FLASH_lnk_cpu1.cmd`, `2837xD_RAM_lnk_cpu1.cmd` - Linker command files for FLASH and RAM builds.

Build Instructions
------------------

Requirements:
- GNU Make (or use Code Composer Studio which can import the project)
- TI C2000 compiler / Code Composer Studio (CCS) toolchain matching the target device
- Git (for repository operations)

Build from command line (example):

1. Open a developer PowerShell / MSYS2 / Bash shell with the toolchain in PATH.
2. From the repository root, run:

```
make -f makefile
```

This will invoke the included make rules and build the default CPU1 target. For CCS usage, import the project or use the provided CCS project files under `CPU1_FLASH` / `CPU1_RAM`.
