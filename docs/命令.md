##  上位机下发指令

| **串行请求** | **描  述**                                                   | **说明/示例**                                                |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| C            | Close the valve                                              | 与按下关闭按钮功能相同                                       |
| O            | Open the valve                                               | 与按下打开按钮功能相同                                       |
| H            | 阀门保持当前位置                                             | 如果设备处于该模式时，则停止压力控制                         |
| T1x          | 设置设定点#1的类型  当x=0时，设定点类型为位置。  当x=1时，设定点类型为压力。 |                                                              |
| S1xx.xx      | 用于编程设定值xx.xx是0.00和100.00之间的任意数字，表示仪表满刻度的百分比。 | 例如S150, 编程设定点的50%的值。  当使用1torr规时，相当于500mtorr。 |
| D1           | 激活设定点#1。                                               | 将设备置于控制模式，有效地激活设定点。                       |
| Vxx.xx       | 运动至阀门位置                                               | xx.xx  为全开的 0 to 100%                                    |
| L0           | 自动选择CDG1或CDG2以获得最佳分辨率                           | 默认的两个仪表配置                                           |
| L1           | 仅控制和报告CDG1值                                           | 为维护功能选择 真空规1                                       |
| L2           | 仅控制和报告CDG2值                                           | 为维护功能选择 真空规2                                       |
| M            | 将阀门发送到由三个旋转开关定义的位置，作为打开的百分比       | 与按下QP3控制器上的MID开关功能相同。此命令仅在QP3控制器上可用。 |
| N1xx         | 设置CDG1的满刻度范围                                         | xx的值见表1                                                  |
| N2xx         | 设置CDG2的满刻度范围                                         | xx的值见**表6.3**                                            |
| J4           | 清除某些TPV和TSS控制器上包含的“初始化安全锁功能”             | 初始化阀门                                                   |
| DPRxx.xx     | 阀门运动到xx.xx设定位置                                      | xx.xx  为全开的 0 to 100% ，直接动作指令                     |
| DPOxx.xx     | 阀门调压至xx.xx设定的压力值                                  |                                                              |

## 请求和响应

| **串行请求** | **描  述**         | **响    应**                                               |
| ------------ | ------------------ | ---------------------------------------------------------- |
| R1           | 请求设定点值       | S1+xxxx，其中xxxx是一个从0.00到100.00的数字                |
| R5           | 请求当前压力值     | P+xxxx, 其中xxxx是一个从0.00到100.00的数字                 |
| R6           | 请求当前阀位       | V+xxxx, 其中xxxx是一个从0.00到100.00的数字                 |
| R38          | 请求软件版本       | IQ+3-[版本号 #] [版本日期] (文本)                          |
| R26          | 报告设定点类型     | T1x, 当x=0时，设定点类型为位置。当x=1时，设定点类型为压力. |
| GSN          | 获取该设备的序列号 | SN: xxxxxxxx                                               |
| RN1          | 请求CDG1 的满量程  | N1xx.xx, 其中xx.xx是单位为Torr的CDG1的满量程范围           |
| RN2          | 请求CDG2 的满量程  | N2xx.xx, 其中xx.xx是单位为Torr的CDG2的满量程范围           |
| RESET        | 重置设备           | 与cycling  power 功率相同                                  |
